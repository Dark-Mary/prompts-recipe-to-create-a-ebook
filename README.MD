# Projeto EBOOK Gerado por I.A.s


 > ℹ️ **NOTE:** Este repositório foi elaborado durante o Bootcamp promovido pela Caixa na DIO como um desafio proposto pelo professor Felipe Aguiar

Projeto com o objetivo de gerar um ebook digital com as facilidades das ferramentas de IA. todos os prompts
seguem abaixo.

<a href="https://github.com/felipeAguiarCode/prompts-recipe-to-create-a-ebook/blob/main/output/ebook%20-%20css%20jedi%20output.pdf" title="View PDF now"> 📕Clique aqui para ler</a>

## 💻 Tecnologias utilizadas no projeto

- [ChatGPT](https://chat.openai.com/) 
- [MidJourney](https://www.midjourney.com/app/)
- [DocsGoogle](https://docs.google.com/)

## 🧠 Prompts


ChatGPT：

|   Ação   | prompt                                                                                                                                                                                                                                                                         |
| :------: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
|  título  | Crie um título de um ebook sobre o tema de banco de dados, o ebook é do nicho de programação e o subnicho é de banco de dados, o título deve ser épico e curto, e tenha uma temática de Super Mario no título, me liste 5 variações de títulos                                                        |
| conteúdo | Faça um texto para ebook , com foco em Banco de Dados, listando os principais tipos com exemplos em código {REGRAS} Explique sempre de uma maneira simples Deixe o texto enxuto, Sempre traga exemplos de código em contextos reais , sempre deixe um título sugestivo por tópico |


Midjourney：

|  Ação  | prompt                                                                                 |
| :----: | -------------------------------------------------------------------------------------- |
| título | Mario with his back turned, running in a blocky corridor like in the game, pixel art style --v 5.1 |

## ✨ Features

- Conteúdo gerado via ChatGPT
- Imagens geradas via MidJourney

## 📚 Materiais

- Imagens utilizadas em `assets`
- ebook gerado durante as aulas em `output`
